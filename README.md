# Demos

Small, self-contained demo projects and scripts.

## Demos

| Demo | What it shows | Folder |
| --- | --- | --- |
| Intune + Microsoft Graph (PowerShell) | OAuth 2.0 against Microsoft Graph to access Intune RBAC-protected resources — client credentials and device-code flows, JWT claim inspection, managed devices, compliance policies, and Intune role definitions / assignments | [`intune-graph-rbac/`](intune-graph-rbac/) |

Each demo folder has its own README with setup and run instructions. No secrets, tenant IDs, or client IDs are committed here — bring your own Entra app registration.
